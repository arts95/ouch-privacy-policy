## Google Play & Google API Services User Data Policy Compliance

The Ouch app adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the **Limited Use** requirements:

1. **Local-First:** All financial data and vehicle logs are stored directly on the user's device.
2. **User Data Ownership:** Data synced to Google Drive / Google Sheets resides exclusively in the user's personal Google Drive account.
3. **No Third-Party Advertising or Selling:** User data is never sold, transferred to third parties, or used for personalized advertising or AI model training.
4. **Direct Secure Communication:** Credentials (such as bank tokens and OAuth tokens) are stored in secure device storage (`SecureStore`) and only communicate directly with official provider APIs over HTTPS.
